## Projects

*In rhythm games, a **chart** is the "note map" that defines the gameplay of a song. My tools help create and convert charts.*

### BeatUp Engine
A lightweight 2D rhythm game engine with a built-in chart editor, written in C++ with SDL2 and Dear ImGui. It simulates classic 6-key + spacebar arcade rhythm games with low latency and precise timing.

[Project page](https://web.beatupengine.workers.dev/bue.html)

[![BeatUp Engine](https://web.beatupengine.workers.dev/assets/menustate.png)](https://web.beatupengine.workers.dev/bue.html)

### SanConverter
A C# / WPF desktop app (.NET 4.8) that converts `.SM` / `.SSC` chart files to the `.SLK` format, including Beat Up and One-Two Party logic.

[Project page & download](https://web.beatupengine.workers.dev/sanconverter.html)

[![SanConverter](https://web.beatupengine.workers.dev/assets/sanconverter.png)](https://web.beatupengine.workers.dev/sanconverter.html)
